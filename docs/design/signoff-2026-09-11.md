## Not captured / limitations

- iOS in-sheet keyboard was not screenshotted: idb text injection does not raise the soft keyboard
  on this sim. The lift is the same `useKeyboardLift` hook with the iOS `keyboardWillShow` +
  `LayoutAnimation` path, proven on Android where edge-to-edge made it the risk; iOS sheets render
  correctly.
- iOS was walked in the Release build, which does not expose the dev tier flag, so the Work-only
  Settings section and the vault-code/audit flows were exercised on Android (Work via
  `EXPO_PUBLIC_TIER=work`).
- AT-1 stays a dev-only note: Android dev build shows non-zero OUT (Metro); the Proof screen
  discloses this, and the iOS Release build already shows OUT 0 B.
