## Headline

**The two blockers from the 2026-09-06 web review are fixed.** IBM Plex Sans/Mono are now bundled and
loaded (splash-gated), with proper fallback stacks: no serif anywhere, and the mono telemetry is truly
monospaced on device. The composer attach and mic are now working vector icons, not disabled stubs.
Text size now scales to 200% and reflows the whole UI. Onboarding, the keyboard-open case, and the
technical UX all pass on device.

The initial walkthrough (below) found the paywall showing only the Pro card (Work hidden). **That is now
resolved on the current main** — see the "Re-verification" section at the end: the paywall shows Pro first
and Work ("FOR PROFESSIONALS") below, and a new keyboard-under-sheet FAIL is noted there.

## What is right — keep it

- **Fonts fixed**: IBM Plex Sans/Mono bundled and loaded, splash-gated, with fallback stacks
  (`apps/mobile/src/services/fonts.native.ts`, `packages/ui/src/tokens.ts`). No serif; mono is monospaced.
- **Keyboard-open on Android edge-to-edge**: the composer and the last answer both stay visible above
  the keyboard. This was the highest risk and it works.
- **Real on-device inference** runs from the pushed model: correct arithmetic, a clean Python code block
  with a Copy action and contained horizontal scroll.
- **Attach/mic are live**: functional vector icons and a working attach sheet (Photo / Camera / Strict
  mode / Manage documents).
- **Text size to 200%** reflows the entire UI without breakage.
- **Platform honesty and platform-correct copy** on both: "Delivered by Google Play", "Internet: granted
  · development build only (Metro)", iOS App Privacy Report, Face ID / Touch ID, "iOS cannot block
  screenshots", Family Sharing wording.
- **Lock screen** shows the right copy and sets FLAG_SECURE (screenshots blocked).
- Palette, seal states, motifs, chat anatomy and Markdown all render on device as the spec describes.

## Not verified this session

- iOS keyboard-visible avoidance (idb injects text without raising the soft keyboard; proven on Android).
- Voice mode UI (Pro-gated; needs a Pro entitlement the sim/emulator can't grant without a store).
- Vault "loaded" state (the side-loaded model shows a Play-delivery bind error; needs real asset delivery).
- Personas, Memory, chats drawer swipe/select, new-chat sheet (covered at code/web level in the prior
  review, not re-walked here).
