07מפת פיצ'רים: חינם / Pro / Pro for Work

עיקרון החלוקה: כל מה שמתחרים חינמיים כבר נותנים, וכל מה שהופך את הבטחת הפרטיות לאמינה, נשאר חינם. מה שנמכר הוא עוצמה מתמשכת ועבודה: מסמכים, זיכרון, קול, אינטגרציות ושליטה. אפליקציית פרטיות שגובה כסף על פרטיות נקראת "הונאה" בביקורות (Layla, Venice), ולכן שום פיצ'ר אמון אינו מאחורי תשלום.

מה אף אחד בקטגוריה לא מספק היום (עמדות פתוחות שאנחנו תופסים): מנעול אפליקציה ביומטרי, מצב אינקוגניטו, מחיקת חירום, חסימת צילום מסך, גיבוי מוצפן במשפט‑סיסמה, מצב "אפס רשת" שניתן לאימות, כפתור דיווח בתוך האפליקציה (דרישת Play), זיכרון על המכשיר בשליטת המשתמש, הרחבת מקלדת, וממשק הזרמה שעבר ביקורת נגישות.

7.9 סיכום שכבות

Free: מוצר שלם. צ'אט ראשון בלי הורדה, קטלוג + HF + ייבוא, הורדות אמינות, שיחות ללא הגבלה, עריכה/יצירה מחדש, Markdown + LaTeX, קובץ אחד לשיחה, 3 פרסונות, 6 פעולות מהירות, הקראה והכתבה, מנעול, DB מוצפן, אינקוגניטו ומחיקה אוטומטית, מחיקת חירום, חסימת צילום, הוכחת אפס רשת, share sheet, Shortcut בסיסי, ווידג'ט, benchmark, presets להקשר, טמפרטורה, נגישות מלאה, כל השפות, דיווח, ייצוא שיחה.

Pro (19.99 דולר חד‑פעמי, universal + Family Sharing ב‑iOS): ספריית מסמכים עם ציטוטים + OCR, פרסונות ללא הגבלה + זיכרון, תיקיות/פרויקטים, ייצוא מלא + גיבוי מוצפן + העברה בין מכשירים, קולות נוירוניים + שיחת קול + Whisper, הרחבת מקלדת + פעולות מותאמות + Shortcuts מתקדמים, חיבור LAN, שליטה מתקדמת + speculative decoding + ריבוי מודלים, השוואה, פעולות יומן/אנשי קשר, אייקונים. הכל יכולת מקומית קבועה, ולכן מחיר חד‑פעמי הוא כן.

Pro for Work (69.99 דולר חד‑פעמי, דסקטופ תחילה; Pro משדרגים ב‑49.99): חבילות מקצוע (משפטי, טיפולי, רפואי, חשבונאי) עם תבניות והצהרות, vaults לפי לקוח/תיק עם קוד נפרד, כלי רדקציה/אנונימיזציה לפני הדבקה, קליטת DOCX/XLSX/HTML, הכתבה לרשומות, יומן ביקורת וייצוא מוחתם, מודלים גדולים (Power/Studio), מפתחות רישיון קבוצתיים שמאומתים אופליין, והצהרת ארכיטקטורה להדפסה לתיקי ציות. לעולם לא "HIPAA‑compliant" ולא "privileged" בשיווק.
