ההנחה: מפתח בכיר יחיד ב‑TypeScript עם סוכני קוד, שמפעיל במקביל את מכונת השיווק הקיימת. סדר השלבים קבוע (מובייל → ווב → דסקטופ), שלב 3 מתחיל רק אחרי שער ב' (§15.2, חודש 4), וההחלטות שמעצבות את השלבים המאוחרים מתקבלות בשבוע הראשון.

14.3 שלב 2: ווב (שבועות 13–17)

  • ייצוא ווב, אדפטר wllama עם WebGPU ונפילה ל‑WASM, OPFS עם persist, Service Worker (Workbox) שמאפשר מבחן מצב טיסה בדפדפן.
  • שער מכשיר: דסקטופ עד Sharp; טלפון עד Instant, עם הפניה להתקנת האפליקציה.
  • אירוח: origin נפרד לדמו (COOP/COEP), CSP קשיח, SRI, hash מפורסם; דף שיווק נפרד עם מדריכי SEO (§13).
  • Chrome Prompt API כמתג אופציונלי מסומן "מודל של Google, מנוהל על ידי Chrome".
  • PWA + PWABuilder ל‑Microsoft Store כגשר עד שלב 3.

14.4 שלב 3: דסקטופ Windows ו‑macOS (שבועות 18–25)

  • מעטפת Tauri v2 סביב ייצוא הווב; crate של Rust (llama-cpp-2) או sidecar של llama-server; בניות Vulkan ו‑CUDA ל‑Windows, Metal ל‑macOS; זיהוי GPU ובחירת backend.
  • אדפטרי קבצים ו‑SQLite, drag‑and‑drop של מסמכים ותיקיות, tray עם מצב החותם, קיצורי מקלדת, updater חתום.
  • חתימה: Apple Developer ID + Notarization; Windows Authenticode או Azure Trusted Signing; Microsoft Store כרישום EXE/MSI (או MSIX דרך tauri-windows-bundle); Mac App Store אופציונלי (sandbox).
  • רישוי Pro בדסקטופ: קניה דרך Microsoft Store / Mac App Store, או מפתח רישיון חתום (Paddle/Lemon Squeezy) שמאומת אופליין. Pro אחד לכל המכשירים של אותה חנות; החלטה חוצת‑חנויות ב‑§16.
  • השקת "Pro for Work": מצב מסמכים מרובים, פרויקטים, ציטוטים, ייצוא PDF, וקטלוג Power/Studio.

14.7 רשימת 40 הבדיקות לפני כל שחרור (תמצית)

מכיוון שאין טלמטריה, הרשימה הזו היא הניטור. הגרסה המלאה (T01–T40 עם פקודות, קריטריוני מעבר ואיזה מכשיר שלנו מריץ כל בדיקה) חיה בריפו ב‑docs/qa/release-checklist.md, ומפת 70 מקרי הקצה של §10 ב‑docs/qa/edge-cases-matrix.md; כאן הקטגוריות:

  • התקנה נקייה על מכשיר הרצפה ועל הדגל בשתי הפלטפורמות
  • הורדת מודל: התחלה, ניתוק, המשך, ביטול, מקום מלא, hash שגוי
  • Apple FM: זמין, כבוי, אזור לא נתמך, בהורדה
  • שיחה של 2 שעות רצופות: זיכרון, חום, סוללה
  • רקע באמצע יצירה, שיחה נכנסת, נעילת מסך
  • מנעול, ביומטריה נכשלת, קוד, מחיקת חירום
  • אינקוגניטו: לא נכתב לדיסק (בדיקה עם Instruments)
  • מסמכים: PDF 200 עמודים, סריקה, עברית, קובץ פגום, 0 בייט
  • Pro: רכישה, שחזור, Family Sharing, החזר, מצב טיסה
  • RTL בכל מסך, גודל טקסט 200%, VoiceOver/TalkBack בזמן הזרמה
  • Exodus: אפס טראקרים; מניפסט אנדרואיד: אפס הרשאות רשת (aapt2 dump permissions)
  • מד יציאה: OUT 0 B אחרי הרצת כל התרחישים (mitmproxy מאשר)
  • 16 KB pages באימולטור; iOS 26 Liquid Glass ו‑iOS 18 fallback
  • Reduced motion, ערכה בהירה, דסקטופ/ווב לפי שלב
