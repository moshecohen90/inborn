`AssertionError: expected '18' to be '17'`. That is the guard working, and it moves with the bump.

## Build

```
cd apps/mobile && npx expo prebuild -p ios --no-install && (cd ios && pod install)
DEVELOPMENT_TEAM=NGCHN95667 ruby scripts/ios-add-storekit-tests.rb ios/Inborn.xcodeproj Inborn
cd ios && xcodebuild -workspace Inborn.xcworkspace -scheme Inborn -configuration Release \
  -destination "generic/platform=iOS" -archivePath build/Inborn.xcarchive -derivedDataPath build/dd \
  -allowProvisioningUpdates DEVELOPMENT_TEAM=NGCHN95667 archive
eval "$(../../../scripts/asc-key-env.sh)"
xcodebuild -exportArchive -archivePath build/Inborn.xcarchive -exportOptionsPlist ExportOptions.plist \
  -exportPath build/export -allowProvisioningUpdates -authenticationKeyPath "$INBORN_ASC_KEY_PATH" \
  -authenticationKeyID "$INBORN_ASC_KEY_ID" -authenticationKeyIssuerID "$INBORN_ASC_ISSUER_ID"
xcrun altool --upload-app -f build/export/Inborn.ipa -t ios --apiKey "$INBORN_ASC_KEY_ID" --apiIssuer "$INBORN_ASC_ISSUER_ID"
```

`--cleanup` is deliberately not in that list (F91: `asc-key-env.sh --cleanup` deletes every stream's staged key, not
the caller's own). The two things a fresh worktree needs were done before anything was built: the **`.models`
symlink existed before `pod install`** (F164 — without it the podspec silently drops Tesseract and Hebrew scans stop
being read), and **`ExportOptions.plist` was recreated by hand**, because it is untracked and the prebuild rewrites
`ios/` without it. `scripts/check-store-env.sh` ran first and reported *store env clean*; `env | grep EXPO_PUBLIC`
was empty for the whole run.

**The lock protocol earned its keep.** `android-vc22` held `gradle.running` for a `bundleRelease` when this stream
was ready to archive; the archive waited **6 minutes** and started the second the sentinel went away
(`archive.status`). The wait loop was also given a `pgrep` check for `appname=gradlew` and `xcodebuild -workspace`
alongside the sentinel files, so a stream that forgets its sentinel still cannot be run over.
