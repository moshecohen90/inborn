## Build
```
cd apps/mobile && rm -rf ios && npx expo prebuild -p ios --no-install --clean && (cd ios && pod install)
cd ios && xcodebuild -workspace Inborn.xcworkspace -scheme Inborn -configuration Release -destination "generic/platform=iOS" \
  -archivePath build/Inborn.xcarchive -derivedDataPath build/dd -allowProvisioningUpdates DEVELOPMENT_TEAM=NGCHN95667 archive
xcodebuild -exportArchive -archivePath build/Inborn.xcarchive -exportOptionsPlist ExportOptions.plist -exportPath build/export \
  -allowProvisioningUpdates -authenticationKeyPath AuthKey_<kid>.p8 -authenticationKeyID <kid> -authenticationKeyIssuerID <iss>
xcrun altool --validate-app -f build/export/Inborn.ipa -t ios --apiKey <kid> --apiIssuer <iss>
xcrun altool --upload-app  -f build/export/Inborn.ipa -t ios --apiKey <kid> --apiIssuer <iss>
```
`ExportOptions.plist` is the build-6/7 file (method `app-store-connect`, destination `export`, `signingStyle` automatic,
`uploadSymbols` true, team `NGCHN95667`), copied in beside the regenerated `ios/`. The `.p8` file is written from the
Keychain into a private scratch dir and into `~/.appstoreconnect/private_keys` for the run, and every copy is deleted
afterwards.

## Cloud signing: the Admin key again, unchanged since build 6

Build 7 left this open for the lead and neither remedy was applied, so this run did not spend an attempt on the App Manager
key (Keychain `inborn-asc-api`, key id `4V4PPDXM5A`) and went straight to the **Admin** key
(`store-reviews/appstore-analytics-config`, key id `<asc-key-id>`), exactly as builds 6 and 7 did. Export, `--validate-app`
and `--upload-app` all used it and the export succeeded on the first try.

The underlying fault is unchanged and documented in the build-6 and build-7 docs: Apple answers
`GET /xcbuild/v1/certificates?filter[certificateType]=DISTRIBUTION_MANAGED` for the App Manager key with 403
`FORBIDDEN_ERROR`, resultCode 7495, *"You haven't been given access to cloud-managed distribution certificates."*, and this
Mac has no local distribution identity to fall back on. **Still open for the lead** — either store an Admin key under
`inborn-asc-api`, or grant the App Manager key access to cloud-managed distribution certificates in App Store Connect →
Users and Access → Integrations. Build 9 will hit this again otherwise.
