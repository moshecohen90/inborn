## Method

`adb -s REDACTED-6T`, keys only (TAB / DPAD / ENTER / `input text`), every `uiautomator dump` serialised behind one lock
directory, and **one driver process**. Driver in the session scratch under `android-vc15/drv/`, soak 7's cadence
unchanged: F33 every 5 minutes, a `meminfo` / `thermalservice` / `battery` sample every 5, a new chat every 18, a model
switch every 15, a deep-link visit to vault, settings and proof every 15, prompt cap 45 polls. Completion is soak 7's
detector — the stop button seen then absent twice, with a full-text stability fallback — so the counts here are
comparable with soak 7's and not with soak 6's.

Two captures ran for each window: `logcat -v time --pid=<app>` and `logcat -b events -v time`. `dumpsys dropbox` was
read before the first window and again after the last.

## Two windows, because the first one measured the wrong model

The run was executed twice, and both halves are reported here because together they are the model coverage the run
needed.

The first window's six model switches **never happened**. A `focus_tab` change made earlier the same morning returned
early when the wanted node was not already in the accessibility tree; the vault scrolls, so `use-instant` is genuinely
absent until TAB walks it into view, and `s-model.sh` logged its old fallback line — *"no use-instant reachable
(already in use)"* — for a switch it had not performed. The window ran its full half hour on **Fast** while the log
claimed Instant, and its `TOTAL PSS` samples (1.74–1.79 GB, Fast's level) are what gave it away. `s-model.sh` now reads
the model chip back and fails loudly when it does not match, and the window was re-run.

## Not run

- **F35 hands-free was not exercised**, so `RECORD_AUDIO` was never granted or revoked in this run and the phone's
  permission state was never touched. That is also why there is no process restart to explain.
- **Sharp was never made resident.** Both windows ran Fast and Instant only, as soak 6 and soak 7 did.
- **No Hebrew was ever typed.** `adb shell input text` cannot type Hebrew and the release build has no autoprompt
  hook, so the Hebrew questions in the prompt set are ASCII sentences asking for a Hebrew answer.
- **Window B never switched to Fast.** The loop's min-27 switch fell inside the guard that keeps room before the next
  F33 cycle, so it was skipped; Fast's half hour is window A.
