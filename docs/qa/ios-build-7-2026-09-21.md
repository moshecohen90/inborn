## Build
```
cd apps/mobile && rm -rf ios && npx expo prebuild -p ios --no-install --clean && (cd ios && pod install)
cd ios && xcodebuild -workspace Inborn.xcworkspace -scheme Inborn -configuration Release -destination "generic/platform=iOS" \
  -archivePath build/Inborn.xcarchive -derivedDataPath build/dd -allowProvisioningUpdates DEVELOPMENT_TEAM=NGCHN95667 archive
xcodebuild -exportArchive -archivePath build/Inborn.xcarchive -exportOptionsPlist ExportOptions.plist -exportPath build/export \
  -allowProvisioningUpdates -authenticationKeyPath AuthKey_<kid>.p8 -authenticationKeyID <kid> -authenticationKeyIssuerID <iss>
xcrun altool --validate-app -f build/export/Inborn.ipa -t ios --apiKey <kid> --apiIssuer <iss>
xcrun altool --upload-app  -f build/export/Inborn.ipa -t ios --apiKey <kid> --apiIssuer <iss>
```
`ExportOptions.plist` is the build-6 file (method `app-store-connect`, destination `export`, `signingStyle` automatic,
`uploadSymbols` true, team `NGCHN95667`), copied in beside the regenerated `ios/`. The `.p8` files are written from the
Keychain into a private scratch dir and into `~/.appstoreconnect/private_keys` for the run, and every copy is deleted
afterwards.

## Cloud signing: build 6's finding is unchanged, the Admin key was needed again

The export was tried first with the documented key — Keychain `inborn-asc-api`, key id `4V4PPDXM5A` — and **failed exactly as
in build 6**:

```
error: exportArchive Cloud signing permission error
error: exportArchive No signing certificate "iOS Distribution" found
```

`IDEDistributionProvisioning.log` carries Apple's reason eight times, on
`GET /xcbuild/v1/certificates?filter[certificateType]=DISTRIBUTION_MANAGED`: 403 `FORBIDDEN_ERROR`, resultCode 7495,
*"You haven't been given access to cloud-managed distribution certificates."* This Mac still has no local distribution
identity to fall back on: `security find-identity -v -p codesigning` lists exactly one valid identity,
`Apple Development: Moshe Cohen`.

The run was completed with the **Admin** ASC key (`store-reviews/appstore-analytics-config`, key id `REDACTED-ASC-KEY`), which
Apple accepts for cloud-managed distribution signing. Export, `--validate-app` and `--upload-app` all used it; nothing else
in the recipe changed and the archive was not rebuilt. **Still open for the lead** — neither remedy proposed after build 6
was applied, so build 8 will hit this again: either store an Admin key under `inborn-asc-api`, or grant the App Manager key
access to cloud-managed distribution certificates in App Store Connect → Users and Access → Integrations.
