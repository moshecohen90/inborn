## Build
```
cd apps/mobile && npx expo prebuild -p ios --no-install --clean && (cd ios && pod install)   # withBundledModel: instant.gguf ← … (533 MB); [expo-share-intent] AskInborn target
cd ios && xcodebuild -workspace Inborn.xcworkspace -scheme Inborn -configuration Release -destination "generic/platform=iOS" \
  -archivePath build/Inborn.xcarchive -derivedDataPath build/dd -allowProvisioningUpdates DEVELOPMENT_TEAM=NGCHN95667 archive
xcodebuild -exportArchive -archivePath build/Inborn.xcarchive -exportOptionsPlist ExportOptions.plist -exportPath build/export \
  -allowProvisioningUpdates -authenticationKeyPath AuthKey_<kid>.p8 -authenticationKeyID <kid> -authenticationKeyIssuerID <iss>
xcrun altool --upload-app -f build/export/Inborn.ipa -t ios --apiKey <kid> --apiIssuer <iss> -p <dir with AuthKey_<kid>.p8>
```
`ExportOptions.plist`: method `app-store-connect`, destination `export`, `signingStyle` automatic, `uploadSymbols` true, team `NGCHN95667`.
The `.p8` is written from the Keychain into a private scratch dir for the run and deleted afterwards.
