## Export and validation

`eval "$(scripts/asc-key-env.sh)"` staged the Admin key (no key material printed), then:

```
xcodebuild -exportArchive -archivePath ~/dev/inborn-docs/builds/Inborn-42.xcarchive -exportOptionsPlist <ExportOptions.plist> \
  -exportPath ~/dev/inborn-docs/builds/export-42 -allowProvisioningUpdates -authenticationKeyPath "$INBORN_ASC_KEY_PATH" \
  -authenticationKeyID "$INBORN_ASC_KEY_ID" -authenticationKeyIssuerID "$INBORN_ASC_ISSUER_ID"
xcrun altool --validate-app -f ~/dev/inborn-docs/builds/export-42/Inborn.ipa -t ios --apiKey "$INBORN_ASC_KEY_ID" --apiIssuer "$INBORN_ASC_ISSUER_ID"
scripts/asc-key-env.sh --cleanup
```
