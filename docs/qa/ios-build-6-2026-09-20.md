## Build
```
cd apps/mobile && rm -rf ios && npx expo prebuild -p ios --no-install --clean && (cd ios && pod install)
cd ios && xcodebuild -workspace Inborn.xcworkspace -scheme Inborn -configuration Release -destination "generic/platform=iOS" \
  -archivePath build/Inborn.xcarchive -derivedDataPath build/dd -allowProvisioningUpdates DEVELOPMENT_TEAM=NGCHN95667 archive
xcodebuild -exportArchive -archivePath build/Inborn.xcarchive -exportOptionsPlist ExportOptions.plist -exportPath build/export \
  -allowProvisioningUpdates -authenticationKeyPath AuthKey_<kid>.p8 -authenticationKeyID <kid> -authenticationKeyIssuerID <iss>
xcrun altool --validate-app -f build/export/Inborn.ipa -t ios --apiKey <kid> --apiIssuer <iss>
xcrun altool --upload-app  -f build/export/Inborn.ipa -t ios --apiKey <kid> --apiIssuer <iss>
```
`ExportOptions.plist` is regenerated with the prebuild's `ios/` (method `app-store-connect`, destination `export`, `signingStyle`
automatic, `uploadSymbols` true, team `NGCHN95667`). The `.p8` is written from the Keychain into a private scratch dir and into
`~/.appstoreconnect/private_keys` for the run, and both copies are deleted afterwards.

## Cloud signing: the App Manager key no longer works, the Admin key does

The export first ran with the documented key — Keychain `inborn-asc-api`, key id `4V4PPDXM5A` — and **failed**:

```
error: exportArchive Cloud signing permission error
error: exportArchive No signing certificate "iOS Distribution" found
```

`IDEDistributionProvisioning.log` has Apple's reason, on `GET /xcbuild/v1/certificates?filter[certificateType]=DISTRIBUTION_MANAGED`:
403 `FORBIDDEN_ERROR`, resultCode 7495, *"You haven't been given access to cloud-managed distribution certificates."* That key is the
App Manager key (it is the same key the ASO tooling keeps as `store-reviews/appstore-manager-config`), and this Mac has **no local
distribution identity to fall back on**: `security find-identity -v -p codesigning` lists exactly one valid identity, `Apple Development:
Moshe Cohen`, while the two distribution certificates in the login keychain expired in 2024 and 2025.

The run was completed with the **Admin** ASC key (`store-reviews/appstore-analytics-config`, key id `<asc-key-id>`), which Apple accepts
for cloud-managed distribution signing. Export, `--validate-app` and `--upload-app` all used it; nothing else in the recipe changed and
the archive was not rebuilt. **Decision for the lead:** either store an Admin key under `inborn-asc-api`, or grant the App Manager key
access to cloud-managed distribution certificates in App Store Connect → Users and Access → Integrations, before build 7.
