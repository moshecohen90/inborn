answered, with `CoreDeviceService` at 93% CPU. Moshe's container was therefore pulled **before** the install with
pymobiledevice3 (`apps pull`). The lead then restarted CoreDeviceService. The install and the after-pull used
`devicectl`, as in build 18 (`raw/install19.txt`).
