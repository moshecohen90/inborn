### Reading the F39 tables out of Hermes bytecode

Worth recording for the next build: `strings main.jsbundle` finds **none** of the round-20 regexes, and that is not a
missing fix. Hermes keeps its string table in two encodings — ASCII strings as one byte per character, anything with a
non-ASCII character as **UTF-16LE**. Three of the four F39 tables carry non-ASCII (`cómo`, `spät`/`heißt`, and the whole
Hebrew/CJK half of `EXPLAIN_MARKS`), so the entire regex source is stored as UTF-16 and an ASCII `strings` pass cuts it
into single letters. Searching the raw bytes in both encodings finds each table's exact source from `length.ts`, once:

| table | source length | found as |
|---|---|---|
| `EXPLAIN_STARTS` | 219 chars | UTF-16LE ×1 |
| `EXPLAIN_NOT` | 204 chars | UTF-16LE ×1 |
| `EXPLAIN_MARKS` | 834 chars | UTF-16LE ×1 |
| `CHOICE_MARK` | 23 chars | UTF-8 ×1 (pure ASCII) |

Spot checks inside those strings, all ×1: `pros and cons|advantages and disadvantages`, `vor- und nachteile`,
`wie (?:viel|viele|alt|hoch`, `comment (?:s'appelle|vous appelez)`, `ventajas y desventajas`, `walk me through`,
`difference between`, `יתרונות וחסרונות`, `ספר לי על`, `どうやって`, `説明して`, `어떻게`, `怎麼`.

## Cloud signing: the Admin key again, unchanged since build 6

Builds 6–10 all left this open for the lead and neither remedy has been applied, so this run did not spend an attempt on
the App Manager key (Keychain `inborn-asc-api`) and went straight to the **Admin** key
(`store-reviews/appstore-analytics-config`, key id `REDACTED-ASC-KEY`, `role` Admin). Export, `--validate-app` and
`--upload-app` all used it and the export succeeded on the first try.

The underlying fault is unchanged and documented in the build-6 doc: Apple answers
`GET /xcbuild/v1/certificates?filter[certificateType]=DISTRIBUTION_MANAGED` for the App Manager key with 403
`FORBIDDEN_ERROR`, resultCode 7495, *"You haven't been given access to cloud-managed distribution certificates."*, and
this Mac has no local distribution identity to fall back on. **Still open for the lead** — either store an Admin key
under `inborn-asc-api`, or grant the App Manager key access to cloud-managed distribution certificates in App Store
Connect → Users and Access → Integrations. Build 12 will hit this again otherwise.
