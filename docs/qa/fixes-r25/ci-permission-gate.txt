`android.blockedPermissions` (app.config.ts), so every permission the dependencies contribute survives the merge:

## 3. The near-miss the gate now refuses
The pre-merge `apps/mobile/android/app/src/main/AndroidManifest.xml` lists INTERNET with tools:node="remove" and
nothing else outside the allowlist, so a gate that read it would pass while no dependency manifest had been merged
yet. The script now requires a <uses-sdk> block and no tools namespace, which only the merged file has, and exits 2.
Covered together with the two sabotage cases by apps/mobile/test/androidPermissionGate.test.ts (5 tests).
