## Cloud signing: the Admin key again, unchanged since build 6

Builds 6–9 all left this open for the lead and neither remedy has been applied, so this run did not spend an attempt on
the App Manager key (Keychain `inborn-asc-api`) and went straight to the **Admin** key
(`store-reviews/appstore-analytics-config`, key id `<asc-key-id>`, `role` Admin). Export, `--validate-app` and
`--upload-app` all used it and the export succeeded on the first try.

The underlying fault is unchanged and documented in the build-6 doc: Apple answers
`GET /xcbuild/v1/certificates?filter[certificateType]=DISTRIBUTION_MANAGED` for the App Manager key with 403
`FORBIDDEN_ERROR`, resultCode 7495, *"You haven't been given access to cloud-managed distribution certificates."*, and
this Mac has no local distribution identity to fall back on. **Still open for the lead** — either store an Admin key
under `inborn-asc-api`, or grant the App Manager key access to cloud-managed distribution certificates in App Store
Connect → Users and Access → Integrations. Build 11 will hit this again otherwise.
